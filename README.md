# SalonAdmin — téléchargement

Application Android de gestion des rendez-vous pour salons de coiffure/beauté.

**[Télécharger la dernière version (APK)](https://github.com/GraphyMotion/salonadmin-releases/releases/latest/download/SalonAdmin.apk)**

## Installation
1. Ouvrir le lien ci-dessus sur le téléphone ou la tablette Android (8.0 minimum).
2. Autoriser l'installation depuis cette source si Android le demande.
3. Ouvrir SalonAdmin, saisir le domaine du salon et le mot de passe admin.
4. Accepter les notifications et désactiver l'optimisation de batterie pour que les alertes sonnent écran éteint.
